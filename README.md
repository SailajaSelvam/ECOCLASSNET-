# ECOCLASSNET - CNN-based Garbage Classification System

Efficient garbage classification is essential for waste management and 
environmental sustainability. Manual segregation is time-consuming and prone 
to errors. This project employs a CNN, a type of deep learning model, to 
automate the classification of garbage into predefined categories such as paper, 
plastic, metal, glass, and organic waste.

## Objectives
- Develop a CNN model for automated garbage classification.
- Achieve high accuracy on waste images.
- Create a scalable system for real-world deployment.

## Dataset
- Dataset Name: Garbage Classification Dataset
- Source: Kaggle or curated dataset
- Classes: Organic, Plastic, Metal, Paper, Glass, Others
- Total Images: 2,500

## Methodology
- **Data Preprocessing:** Resizing, normalization, augmentation
- **CNN Architecture:** Convolutional + Pooling + Dropout + Dense layers
- **Training:** Adam optimizer, categorical crossentropy, batch size 32, 30 epochs
- **Evaluation Metrics:** Accuracy, Precision, Recall, F1-Score

## Usage
1. Clone the repo:
   git clone https://github.com/SailajaSelvam/ECOCLASSNET.git

2.Install dependencies:
  pip install -r requirements.txt

3.Run the training script
